# KiCAD Usage

Download KiCAD from [official website](https://www.kicad.org/download/).

Add custom library from [Espressif](https://github.com/espressif/kicad-libraries).

Follow the [tutorial](https://docs.kicad.org/master/de/getting_started_in_kicad/getting_started_in_kicad.html) to learn how to use KiCAD.
For more information, please refer to the [KiCAD documentation](https://docs.kicad.org/).
